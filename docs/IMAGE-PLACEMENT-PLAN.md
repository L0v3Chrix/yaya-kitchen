# YaYa's Kitchen — Image Placement Master Plan

## The Story We're Telling

**The visitor journey:**
1. **Arrival** — Emotional hook: "This is care, not just food"
2. **Understanding** — What YaYa's Kitchen is and why it exists
3. **Discovery** — What's in the basket, how it works
4. **Connection** — Meet Yaya, feel the warmth
5. **Action** — Place an order

Every image must advance this narrative. No decoration for decoration's sake.

## Image Treatment Guidelines

### Consistent Visual Language

| Attribute | Standard |
|-----------|----------|
| **Color temperature** | Warm (slightly golden) |
| **Contrast** | Medium-high (not flat, not harsh) |
| **Saturation** | Natural, avoid over-saturation |
| **Shadows** | Lifted slightly (no pure blacks) |
| **Highlights** | Soft, not blown out |

### Cropping Philosophy

- **Portraits (sections):** 3:4 ratio, food centered with breathing room
- **Landscapes (breaks):** 16:5 panoramic for full-width sections
- **Squares (gallery):** 1:1, tight crops that show texture and detail
- **Hero:** 16:9, with safe zones for text overlay

### Text Overlay Considerations

For images that will have text on top (hero, possibly full-width breaks):
- Ensure one side has enough "quiet space" (solid-ish color) for text
- May need subtle gradient overlay (dark-to-transparent) for readability
- Test white AND dark text to see which reads better
